## 一、为什么要做这件事？

**核心矛盾：产品能力完备，缺流量。** 之前的 GTM 方向正确，但资源有限全面铺开难以出彩。需要一个引爆点，聚焦资源砸穿一个口子。

**2026 美加墨世界杯是不可错过的窗口：**

| 维度 | 数据 |
|------|------|
| 全球观众 | 35 亿+ |
| 开赛时间 | 6 月 11 日（距今 8 周） |
| 预测市场交易量 | Polymarket 2025 年 $44B+ |
| Polymarket 估值 | ~$90 亿（纽交所母公司领投） |

**一句话：世界杯是全球最大流量事件，预测市场已有成熟用户习惯，我们用 AI 分析能力切入，承接流量转化为商业价值。**

## 二、怎么做？

### 产品定位：官网主阵地 + 预测市场生态引流

- **主阵地**：antalpha.com/worldcup（品牌曝光 + 用户转化）
- **引流钩子**：在 Polymarket 等预测市场生态内发布分析内容，导流回官网
- **交易执行**：作为 Polymarket Builder 享有 gasless 交易特权，AI 分析 + 一键投注闭环

**合规清晰：** 提供分析 + 交易执行工具，资金在用户钱包，零托管。与提供股票分析工具同一逻辑。

### 核心功能（5 个必做）

| 功能 | 用户看到什么 |
|------|------------|
| 每日赛事预测 | 胜负/比分预测 + AI 置信度 |
| 赔率对比 | AI 预测 vs 预测市场赔率，找价值洼地 |
| AI 投注执行 | 发现 Edge → 一键下单（Builder gasless） |
| 预测战绩排行 | 准确率公开透明，建立信任 |
| 实时赔率追踪 | 比赛中赔率变化 |

**一句话差异：ChatGPT 说"德国可能赢"，Antalpha 显示"德国 58%，比分 2-1，市场定价 55%，Edge +3%，一键下注"。**

### 预测引擎（简要）

基于学术研究和开源生态调研，采用行业验证的方案：

- **CatBoost + Elo 评分** — 公开基准最佳准确率（~56%）
- **Dixon-Coles 模型** — 行业黄金标准比分预测
- **独家足球数据库** — 内部数据源，全球无人用此数据做真实比赛预测，**核心差异化壁垒**

## 三、流量怎么来？怎么传？

### 3.1 三层传播飞轮

```
人传人（P2P）：用户分享预测卡片 → 朋友看到 → 注册 → 也分享
Agent 传 Agent（A2A）：Agent 调用我们的 Skill → 输出带品牌水印 → 其他 Agent 主人看到 → 注册
社媒矩阵：Twitter/X + Telegram + Moltbook → 每日预测内容 → 引流回官网
```

### 3.2 病毒传播设计

| 机制 | 为什么能传播 |
|------|------------|
| **预测卡片** | 每场比赛生成精美卡片，用户一键分享。分享的是"自己的判断依据"，不是广告 |
| **预测挑战赛** | "你 vs AI" 比拼准确率，激发胜负欲。Top 10 奖励 API 额度。用户为炫耀而分享 |
| **世界杯专属 Skill** | 发布 `worldcup-predictor` Skill，所有 Agent 调用时自动带品牌水印，零人工成本 |

### 3.3 社媒矩阵

| 平台 | 策略 | 频率 |
|------|------|------|
| **Twitter/X** | 每日预测卡片 + 赛后战报 + Edge 分析 | 每天 1-2 条 |
| **Telegram** | 渗透 15-20 个体育/ Web3 群，以数据分享姿态出现 | 每天 1 条 |
| **Moltbook** | Agent 自动发帖，7×24 覆盖 | 每天 2-3 条 |
| **即刻/知乎** | 中文渠道覆盖 | 每天 3-5 条 |

### 3.4 KOL 合作

世界杯期间扩展到**体育 + Web3 交叉领域**：

- 体育博彩 KOL（3-5 人）：提供预测数据 + Edge 分析
- Web3 KOL（5-10 人）：提供免费 API + gasless 交易
- AI/数据 KOL（2-3 人）：提供技术 API

为 KOL 提供现成素材（预测卡片图片、专属推荐码），降低合作门槛。

## 四、流量怎么变收入？

**核心逻辑：世界杯不是直接变现，是品牌引爆 → 信任积累 → 漏斗筛选 → 转化承接。**

```
世界杯流量涌入（球迷 + 博彩用户 + 开发者）
  │
  ├── 球迷：看了预测 → 走了 ✅ 完成品牌曝光
  ├── 博彩用户：看了预测 → 一键下注 → 走了 ✅ 完成产品体验
  └── 开发者/量化：看了预测 → "这个 AI 怎么做到的？" → ⭐ 注册 API Key
       │
       ▼
  Free Tier → 高频用户升级 Pro（月费）       ← v2.3 Layer 1
  Token 算力包（策略持续运行）               ← v2.3 Layer 2
  自营金融产品引流（定期/活期）              ← v2.3 Layer 3
```

**世界杯后不断流：** 7 月世界杯结束 → 8 月五大联赛回归 → 9 月欧冠 → 常态化体育预测。世界杯是 Launch Event，不是一次性活动。

**一个开发者的 LTV 远超 100 个球迷。** 流量中有 1% 转化为开发者，就值回整个投入。
