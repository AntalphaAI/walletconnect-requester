## 🐙 @antalpha/skills 项目详解

### 一、项目定位

这是一个基于 **NestJS + MCP SDK** 的 **Monorepo MCP 服务**，通过 HTTP（Streamable HTTP / SSE）向外部 AI Agent 暴露一系列链上业务工具。

---

### 二、目录结构

```
antalpha-skills/
├── apps/mcp-skills/           ← 🔵 主应用入口
│   ├── src/main.ts            ← 启动脚本（dotenv + Nacos配置加载）
│   ├── src/app.module.ts      ← NestJS 根模块
│   └── src/mcp/               ← MCP 核心
│       ├── mcp.controller.ts  ← /mcp 路由（POST/GET/DELETE）
│       ├── mcp.service.ts     ← 协议处理（Session 管理）
│       └── client-ip.util.ts  ← 客户端 IP 提取
│
├── libs/shared/               ← 🟡 公共基础设施
│   └── src/mcp-tool-provider.interface.ts  ← 技能注册接口
│
└── libs/skills/               ← 🟢 业务技能库
    ├── agent/      ← Agent 注册 + SQLite 鉴权
    ├── asset/      ← DeBank 钱包/资产查询
    ├── web3-trader/ ← 0x DEX 报价 + 换币页生成
    ├── smart-money/ ← Moralis 聪明钱追踪
    └── test/       ← 测试用工具
```

---

### 三、HTTP 路由

| 路由 | 说明 |
|------|------|
| `POST/GET/DELETE /mcp` | MCP 协议入口，处理 Session 和工具调用 |
| `GET /web3-trader/...` | 换币页面预览路由 |

---

### 四、服务启动方式

#### 开发环境（推荐）
```bash
cd ~/antalpha-com/antalpha-skills
pnpm install
cp apps/mcp-skills/.env.example apps/mcp-skills/.env
# 编辑 .env，填入 NACOS_SERVER 和 NACOS_NAMESPACE（必须）
pnpm run dev:mcp-skills
```
服务启动后会监听 **3830 端口**。

#### 生产环境
```bash
pnpm run build:mcp-skills
pnpm run start:mcp-skills
```

---

### 五、配置加载机制（关键）

```
启动 → main.ts
  ↓
NODE_ENV=development?
  ├─ Yes → 读取 apps/mcp-skills/.env（本地）
  └─ No  → 跳过 .env，直接用系统环境变量
  ↓
连接 Nacos 配置中心（必填：NACOS_SERVER + NACOS_NAMESPACE）
  ↓
从 Nacos Data ID "antalpha-skills" 拉取业务配置
  ↓
支持 dotenv 格式 或 YAML 格式
  ↓
注入到 process.env → NestJS 启动
```

**核心必填环境变量：**
| 变量 | 说明 |
|------|------|
| `NACOS_SERVER` | Nacos 服务器地址（如 `mcp-nacos-test.metalpha.fund`） |
| `NACOS_NAMESPACE` | Namespace ID（不是显示名！） |
| `NACOS_DATA_ID` | 配置项，默认 `antalpha-skills` |

**业务配置（Nacos 内维护）：**
- `ZEROEX_API_KEY` — 0x 换币
- `DEBANK_ACCESS_KEY` — 链上资产
- `MORALIS_API_KEY` — 聪明钱追踪
- `SMART_MONEY_*` — 扫描参数

---

### 六、暴露的 MCP 工具一览

| 技能库 | 工具用途 |
|--------|---------|
| **agent** | Agent 注册到 SQLite（API Key 鉴权） |
| **asset** | DeBank 钱包查询、多源 Token 列表 |
| **web3-trader** | 0x DEX 报价、换币页生成/预览 |
| **smart-money** | Moralis 聪明钱钱包扫描、信号推送 |

---

### 七、技术栈

```
NestJS 11 + Express 5
@modelcontextprotocol/sdk（ MCP 协议）
better-sqlite3（Agent 数据）
Nacos（配置中心）
Zod（配置校验）
Biome（代码风格）
TypeScript + pnpm monorepo
```

---

### 八、踩坑提醒 ⚠️

1. **NACOS_NAMESPACE 必须填 ID**，不是显示名，否则会连接失败
2. **非开发环境不读本地 .env**，业务全靠 Nacos 注入
3. **请求体有 1MB 限制**（`MCP_MAX_BODY_BYTES`），超限返回 413
4. **工具过滤器**：`MCP_TOOL_FILTER` 环境变量可以白名单指定只加载哪些工具
