## 1. 产品概述

### 1.1 是什么

在 `antalpha.com` 官网上线一个**单页面 Web3 AI 聊天**，让访客**直接体验 Antalpha 的 MCP 工具**——无需安装、无需配置、无需钱包。

### 1.2 为什么做

| 痛点 | 解决方案 |
|------|---------|
| 用户不装 MCP Server 就无法评估工具 | 浏览器里直接试用 |
| 安装流程导致 70% 流失 | 先体验价值，再决定是否安装 |
| "我为什么不直接用 ChatGPT？" | 每条回答都基于真实链上数据，标注数据来源 |
| 交易工具需要钱包 | 只做模拟构建，不执行交易 |

### 1.3 产品定位

**不是** 通用 AI 聊天。  
**不是** "Web3 版 ChatGPT"。  

**是** 一个 **Interactive Demo（互动演示）**——展示 Antalpha MCP 工具能做什么。  
类比：Vercel 的部署预览，但展示的是 AI 工具。

### 1.4 目标用户

- 正在评估 MCP 工具的 AI Agent 用户
- 想看链上数据但不想写代码的 Web3 交易者
- 对比 Antalpha 与其他方案的开发者

## 3. 交易工具改造：仅模拟，不执行

### 3.1 核心原则

**Demo 聊天页不连接任何钱包。所有交易类工具必须改为"模拟 → 展示"模式，不执行交易。**

### 3.2 改造方案

| 原始工具 | Demo 处理方式 | 用户体验 |
|---------|-------------|---------|
| `swap-quote` | ✅ 保留原样（只读，不执行） | 展示最优路由、价格、滑点——用户看到完整的交易预览 |
| `poly-new` → `poly-market-info` | ✅ 保留原样（只读） | 展示市场详情、赔率、流动性 |
| `cex-market-get-ticker` | ✅ 保留原样（只读） | 展示实时价格和资金费率 |
| `poly-buy` / `poly-sell` | ❌ 不纳入 Demo | 需要连接 Polymarket 钱包 |
| `cex-spot-place-order` | ❌ 不纳入 Demo | 需要配置 CEX API Key |
| `hl-market-order` | ❌ 不纳入 Demo | 需要连接 Hyperliquid 钱包 |
| `smart-swap-create` | ❌ 不纳入 Demo | 需要钱包签名 |

### 3.3 模拟转化引导

当用户意图涉及执行时（如"帮我买 100 USDT 的 ETH"）：

```
🤖 AI 回复：
"已为你找到最优兑换路由：
  100 USDT → 0.0312 ETH（Uniswap V3，以太坊）
  价格影响：0.02% | 滑点：0.05% | Gas：约 $2.30

  ⚠️ 这是模拟预览，不会执行任何交易。
  如需真实执行：
  1. 将 Antalpha MCP 接入你的 AI Agent（OpenClaw / Claude Code）
  2. 使用 swap-full 工具配合你的钱包
  [获取 API Key →]  [安装指南 →]"
```

**关键：** 模拟结果本身必须足够有说服力，让用户愿意去安装。

## 6. 后端架构

### 6.1 整体架构

```
用户浏览器
    ↓ HTTPS POST /api/chat
Chat 后端（Next.js API Route / Node.js）
    ↓ MCP 协议（Streamable HTTP）
Antalpha MCP Server（mcp-skills.ai.antalpha.com）
    ↓
外部 API（DeFiLlama、Moralis、0x、Polymarket、OKX）
```

### 6.2 API 规范

**端点：** `POST /api/chat`

**请求体：**
```json
{
  "message": "帮我找最佳稳定币收益",
  "session_id": "可选-会话-UUID",
  "conversation_history": [
    { "role": "user", "content": "..." },
    { "role": "assistant", "content": "..." }
  ]
}
```

**响应体：**
```json
{
  "reply": "找到 3 个稳定币收益机会...",
  "tool_calls": [
    {
      "tool": "investor_discover",
      "status": "success",
      "data": { ... },
      "data_source": {
        "name": "DeFiLlama",
        "url": "https://defillama.com",
        "freshness": "实时",
        "record_count": 16693
      }
    }
  ],
  "is_simulation": false,
  "cta": {
    "type": "api_key",
    "text": "想在你的 AI Agent 里使用这些工具？",
    "url": "https://antalpha.com/get-api-key"
  }
}
```

## 8. 非功能性需求

### 8.1 性能

| 指标 | 目标 |
|------|------|
| 首次回复（无工具调用） | < 2 秒 |
| 工具回复（含 API 调用） | < 8 秒 |
| 页面加载（LCP） | < 1.5 秒 |
| 可交互时间（TTI） | < 3 秒 |

### 8.2 安全

- **不连接钱包** — Demo 绝不请求私钥或签名
- **不存储 CEX API Key** — 市场数据使用共享只读 OKX Key
- **速率限制** — 基于 IP，每天 10 条消息
- **不持久化用户数据** — 对话历史仅限会话内（内存或 Redis TTL）
- **CORS** — 仅允许 `antalpha.com` 来源

### 8.3 可访问性

- 移动端响应式（聊天必须能在手机上使用）
- 默认暗色模式（Web3 用户偏好）
- 键盘支持（Enter 发送）

## 11. 实施优先级

### 第一阶段 — MVP（第 1 周）
1. 单页面聊天 UI（输入框 + 消息区域）
2. 意图分类器（基于规则，8 种模式）
3. 接入 4 个 Tier 1 工具（`investor_discover`、`smart-money-signal`、`swap-quote`、`wallet-balance-query`）
4. 每条回复附带数据来源标识
5. 速率限制（10 次/天）
6. "获取 API Key" CTA 按钮

### 第二阶段 — 体验优化（第 2 周）
1. 接入 4 个 Tier 2 工具（`poly-trending`、`cex-market-get-ticker`、`investor_compare`、`poly-market-info`）
2. 交易相关查询的模拟横幅
3. 快捷按钮
4. 移动端响应式设计
5. 暗色模式
6. 成功指标看板
